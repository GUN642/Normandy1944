# Tonquellen

Alle Waffenaufnahmen stammen aus der **Free Firearm Sound Library** von Ben Jaszczak (Kickstarter 2014),
veröffentlicht unter **CC0 1.0** (gemeinfrei). Spiegel: https://github.com/buddingmonkey/FreeFirearmsSFXLibrary

Für das Spiel wurde je ein einzelner Schuss aus den „Prepared SFX“ (nahe Mikrofonposition vor dem Schützen)
herausgeschnitten, auf Mono/44,1 kHz gebracht, ausgeblendet und als MP3 gespeichert.

| Datei | Aufnahme | verwendet für |
| --- | --- | --- |
| rifle_us.mp3 | Springfield M1917, .30-06 (B_24P) | M1 Garand, M1903 Springfield, BAR |
| rifle_de.mp3 | Mosin-Nagant, 7,62×54R (M_21P) | Karabiner 98k, Gewehr 43 |
| mg42.mp3 | Mosin-Nagant, verkürzt (M_21P) | MG 42 (im Feuertakt wiederholt) |
| stg.mp3 | AK-47, 7,62×39 (C_28P) | StG 44 |
| carbine.mp3 | Norinco SKS (U_14P) | M1 Carbine |
| smg.mp3 | Carl Gustaf M45, 9 mm (G_31P) | MP 40, Thompson (tiefer abgespielt) |
| pistol45.mp3 | Colt 1911, .45 ACP (A_42P) | Colt M1911A1 |
| pistol9.mp3 | Walther PPQ, 9 mm (X_39P) | Walther P38 |

Explosionen, Artillerie, Nebelwerfer, Flugzeuge, Wind, Regen und Brandung werden im Spiel synthetisch erzeugt.
